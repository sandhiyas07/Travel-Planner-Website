# ✈️ Travel Planner Website

A modern and responsive **Travel Planner Website** built using HTML, CSS, and JavaScript. This project helps users explore travel destinations, save favourite places, plan trips, and manage estimated travel budgets.

## 🌍 Project Overview

The Travel Planner Website provides a simple and user-friendly interface for organizing travel plans. Users can discover destinations, search and filter places, create personalized trips, and save their trip information using browser LocalStorage.

## ✨ Features

- **Modern UI:** Clean, attractive, and responsive website design.
- **Explore Destinations:** Browse 12 sample travel destinations with images, descriptions, ratings, and estimated prices.
- **Search Destinations:** Search by destination name, country, or category.
- **Category Filtering:** Filter destinations by Beach, Mountain, City, and Nature.
- **Sorting Options:** Sort destinations by price and rating.
- **Favourite Destinations:** Add or remove places from your favourites list.
- **Trip Planner:** Create trips with a trip name, destination, start date, end date, and budget.
- **Travel Notes:** Add notes and reminders to planned trips.
- **My Trips Dashboard:** View saved trips and their travel status.
- **Budget Calculator:** Automatically calculate the total planned trip budget.
- **Trip Management:** Delete trips when they are no longer needed.
- **LocalStorage:** Save favourites and trips in your browser.
- **Responsive Design:** Supports desktop, tablet, and mobile screens.

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code
- Live Server extension (recommended)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/Travel-Planner-Website.git
```

**2. Open the project folder**

```bash
cd Travel-Planner-Website
```

**3. Open the folder in Visual Studio Code**

```bash
code .
```

**4. Run the website**

- Open `index.html` in VS Code.
- Right-click the file.
- Select **Open with Live Server**.

The website will open in your default browser.

## 📖 How to Use

1. Open the Travel Planner Website.
2. Browse the available destinations.
3. Search for destinations or filter by category.
4. Sort destinations by price or rating.
5. Click the heart icon to save favourite destinations.
6. Click **Plan a Trip** to select a destination.
7. Enter the trip name, dates, estimated budget, and optional notes.
8. Click **Save My Trip**.
9. View your saved trips and total planned budget in the My Trips section.
10. Delete trips or remove favourites whenever needed.

## ⚠️ Limitations

- Destination information and prices are sample data for demonstration purposes.
- The website does not provide real-time booking or payment processing.
- Trip information is saved locally in the current browser and is not synchronized across devices.
- Destination images and web fonts require an internet connection.
